# 12-View Ping-Pong Dataset

This folder is for using the data generated by `pybullet_tabletop_12view.ipynb` in the same style as the scripted `outputs/sphere_bounce_m2` pipeline.

The notebook writes:

- `pybullet_outputs/ping_pong_bounce_12view_<camera>.mp4`
- `pybullet_outputs/ping_pong_bounce_12view_cameras.csv`
- `pybullet_outputs/ping_pong_bounce_12view_trajectory.csv`

Run this exporter to create a structured dataset:

```bash
python dataset/export_ping_pong_12view.py
```

It writes:

```text
dataset/outputs/ping_pong_12view/
  rgb/cam00/frame00000.png
  masks/cam00/frame00000.png
  videos/rgb/cam00_front.mp4
  videos/masks/cam00_front.mp4
  cameras.json
  object_poses.csv
  metadata.json
  config.json
```

The masks are RGB-derived blue-ball masks, not PyBullet instance masks. That makes this a useful stand-in for the SAM-2 path: downstream code sees video-side object masks rather than simulator segmentation IDs.

## Use With Segmentation Experiments

Experiment 1:

```bash
python segmentation/01_mask_guided_gaussian_binding/select_ball_gaussians.py \
  --ply gs_sphere_bounce/point_cloud/iteration_7000/point_cloud.ply \
  --masks-root dataset/outputs/ping_pong_12view/masks \
  --cameras-json dataset/outputs/ping_pong_12view/cameras.json \
  --frame 0 \
  --min-camera-hits 2 \
  --out-dir segmentation/01_mask_guided_gaussian_binding/runs/ping_pong_12view_frame00000
```

Experiment 2 object-only 4DGS:

```bash
python segmentation/02_object_only_4dgs/export_object_only_dynerf.py \
  --config dataset/outputs/ping_pong_12view/config.json \
  --masks-root dataset/outputs/ping_pong_12view/masks \
  --output segmentation/02_object_only_4dgs/dynerf_ping_pong_ball_only \
  --background black

modal run modal_app.py \
  --upload-4d \
  --upload-4d-path segmentation/02_object_only_4dgs/dynerf_ping_pong_ball_only

modal run modal_app.py --train-4d
```
