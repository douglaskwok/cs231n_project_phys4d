================================================================================
PATH VARIABLES (edit for your scene / run)
================================================================================

SCENE_DIR     PyBullet scene export (Step 1 teammate artifact)
              Example: dataset/outputs/phys4d_final/ball_drop_3x3_60fps/scene_0004_e0p78_a0p0

RUN_NAME      Object-only 4DGS run id (matches DyNeRF export folder name)
              Example: ball_drop_e0p78_a0p0_object

WU_OUT        Wu 4DGS checkpoint directory (Step 3 teammate artifact)
              Example: ${SCENE_DIR}/4dgs_wu/${RUN_NAME}

EXPORT        DyNeRF export used at train time (frame_map, transforms_*.json)
              Example: 4dgs/experiments/object_only/runs/${RUN_NAME}

OUT           Pipeline output root for this run
              Example: outputs/bounce_pipeline/${RUN_NAME}

Example setup:

  SCENE_DIR="dataset/outputs/phys4d_final/ball_drop_3x3_60fps/scene_0004_e0p78_a0p0"
  RUN_NAME="ball_drop_e0p78_a0p0_object"
  WU_OUT="${SCENE_DIR}/4dgs_wu/${RUN_NAME}"
  EXPORT="4dgs/experiments/object_only/runs/${RUN_NAME}"
  OUT="outputs/bounce_pipeline/${RUN_NAME}"

================================================================================
STEP 4a — Extract trajectory from Wu 4DGS (GPU, touches Wu code only)
================================================================================

Purpose:
  Opacity-weighted 3D centroid of the ball over TRAIN frames only. Writes CSVs
  used by all later steps. This is the only step that imports hustvl/4DGaussians.

Prerequisites:
  - Wu checkpoint: point_cloud.ply + deformation.pth + cfg_args (train-only!)
  - DyNeRF export: frame_map.json and/or transforms_train.json
  - object_poses.csv (optional but recommended for validation plot / MSE)

Command:

  export WU_4DGS_ROOT=third_party/4DGaussians

  python scripts/bounce/step4a_extract.py \
    --canonical "${WU_OUT}/point_cloud/iteration_30000/point_cloud.ply" \
    --deform    "${WU_OUT}/point_cloud/iteration_30000/deformation.pth" \
    --cfg-args  "${WU_OUT}/cfg_args" \
    --dynerf-export "${EXPORT}" \
    --gt-poses "${SCENE_DIR}/object_poses.csv" \
    --out "${OUT}/step4a"

Arguments:
  --canonical   Path to canonical Gaussian PLY (iteration_30000).
  --deform      deformation.pth OR its parent iteration_* folder.
  --cfg-args    Training cfg_args next to the Wu output (checks for --all-train).
  --dynerf-export  Folder with frame_map.json / transforms_train.json.
  --gt-poses    PyBullet GT poses for overlay and Procrustes-aligned MSE check.
  --out         Output directory (creates step4a/ contents).
  --wu-root     hustvl/4DGaussians clone (default: third_party/4DGaussians).
  --device      cuda (default) or cpu.
  --savgol-window, --savgol-polyorder
                Savitzky-Golay smoothing (defaults 5 and 2).

Outputs (${OUT}/step4a/):
  trajectory_raw.csv, trajectory_smoothed.csv, trajectory_plot.png, step4a_meta.json

Acceptance (milestone3):
  - No NaNs; monotonic t_sec; visible bounce on z; train MSE < 0.05 m (aligned)

================================================================================
STEP 4b — Fit bounce physics (CPU only, CSV in → JSON out)
================================================================================

Purpose:
  Fit (p0, v0, g, e, z_g) with scipy so a discrete bounce simulator matches the
  smoothed train trajectory. No Wu / GPU code.

Prerequisites:
  - ${OUT}/step4a/trajectory_smoothed.csv

Command:

  python scripts/bounce/step4b_fit.py \
    --traj "${OUT}/step4a/trajectory_smoothed.csv" \
    --out "${OUT}/step4b"

Arguments:
  --traj        Step 4a smoothed CSV (frame,t_sec,x,y,z).
  --out         Output directory for step4b/.
  --fps         Optional metadata; inferred from t_sec if omitted.
  --free-gravity  Fit g instead of fixing at -9.81 m/s² (default: fixed).
  --gt-poses    Optional object_poses.csv.
  --align-translation-to-gt
                Subtract mean (GT - traj) translation before fitting (world offset).
  --robust-loss, --robust-f-scale
                scipy least_squares robust loss (default soft_l1, 0.05).

Outputs (${OUT}/step4b/):
  physics_params.json, physics_fit_plot.png

Acceptance (warnings printed if missed):
  - e in [0.3, 0.95]; fit_mse < 0.01 m²; bounce count >= 1

================================================================================
STEP 4c — Extrapolate to held-out test frames (CPU only)
================================================================================

Purpose:
  Roll the fitted simulator forward continuously from train through test
  (does NOT re-initialize from p0 on test frames). Writes test-only CSV.

Prerequisites:
  - ${OUT}/step4b/physics_params.json
  - ${EXPORT}/frame_map.json with "train" and "test" lists
  - ${SCENE_DIR}/config.json (optional validation of frame counts)
  - ${OUT}/step4a/trajectory_smoothed.csv (strongly recommended)

Command:

  python scripts/bounce/step4c_predict.py \
    --params "${OUT}/step4b/physics_params.json" \
    --frame-map "${EXPORT}/frame_map.json" \
    --scene-config "${SCENE_DIR}/config.json" \
    --traj "${OUT}/step4a/trajectory_smoothed.csv" \
    --gt-poses "${SCENE_DIR}/object_poses.csv" \
    --out "${OUT}/step4c"

Arguments:
  --params      physics_params.json from Step 4b.
  --frame-map   DyNeRF frame_map.json (defines held-out test frames).
  --scene-config  PyBullet config.json (fps, train_frames / test_frames checks).
  --traj        Step 4a smoothed CSV (boundary check + full plot).
  --gt-poses    Optional GT overlay on trajectory_full_plot.png.
  --out         Output directory for step4c/.
  --fps         Fallback FPS if not in metadata (default 60).
  --strict      Raise if boundary gap >= 1 cm or floor penetration (else warn).

Outputs (${OUT}/step4c/):
  trajectory_predicted.csv  (test frames only)
  trajectory_full_plot.png
  step4c_meta.json

Acceptance:
  - Row count = number of test frames in frame_map
  - boundary_gap_m < 0.01 m (with --traj); z >= z_g

================================================================================
STEP 5 — Composite render: translated object + background (GPU preferred)
================================================================================

Purpose:
  For each held-out test camera view: translate canonical object Gaussians by
  (p_pred - p_ref), merge with static background.ply, rasterize. Uses Wu
  rasterizer with stage=coarse (NO deformation field — avoids double motion).

Prerequisites:
  - Canonical object PLY + Wu cfg_args (same as Step 4a)
  - ${SCENE_DIR}/background_3dgs/background.ply (Step 5a teammate artifact)
  - ${OUT}/step4c/trajectory_predicted.csv
  - ${OUT}/step4a/trajectory_smoothed.csv (defines p_ref = first row)
  - ${EXPORT}/transforms_test.json (camera poses for test views)

Command (full 3DGS composite):

  python scripts/bounce/step5_render.py \
    --canonical "${WU_OUT}/point_cloud/iteration_30000/point_cloud.ply" \
    --bg-ply "${SCENE_DIR}/background_3dgs/background.ply" \
    --predicted "${OUT}/step4c/trajectory_predicted.csv" \
    --ref-traj "${OUT}/step4a/trajectory_smoothed.csv" \
    --dynerf-export "${EXPORT}" \
    --cfg-args "${WU_OUT}/cfg_args" \
    --scene-dir "${SCENE_DIR}" \
    --out "${OUT}/step5"

Fallback (2D ball overlay on GT RGB — milestone3 fallback):

  python scripts/bounce/step5_render.py \
    --canonical "${WU_OUT}/point_cloud/iteration_30000/point_cloud.ply" \
    --bg-ply "${SCENE_DIR}/background_3dgs/background.ply" \
    --predicted "${OUT}/step4c/trajectory_predicted.csv" \
    --ref-traj "${OUT}/step4a/trajectory_smoothed.csv" \
    --dynerf-export "${EXPORT}" \
    --scene-dir "${SCENE_DIR}" \
    --force-overlay \
    --out "${OUT}/step5"

Arguments:
  --canonical   Wu object point_cloud.ply (canonical, not deformed).
  --bg-ply      Static background 3DGS PLY.
  --predicted   step4c trajectory_predicted.csv.
  --ref-traj    step4a trajectory_smoothed.csv (p_ref = first row).
  --dynerf-export  Folder with transforms_test.json.
  --cfg-args    Required for Wu 3DGS path (same as training).
  --scene-dir   PyBullet scene root (rgb/ for overlay fallback backgrounds).
  --out         Output step5/ directory.
  --wu-root     hustvl/4DGaussians path.
  --force-overlay  Skip 3DGS; draw projected sphere on GT images.
  --sphere-radius-m  Ball radius for overlay mode (default 0.1 m).
  --black-background  Clear color black (default: white).

Outputs (${OUT}/step5/):
  renders/{frame:04d}_cam{cam}.png  (e.g. 0060_cam0.png)
  step5_meta.json

Acceptance:
  - One PNG per (test frame, camera); ball visible; no double ball (canonical only)

================================================================================
STEP 6 — Evaluation: trajectory + rendering metrics (CPU)
================================================================================

Purpose:
  Compare held-out predictions to PyBullet GT (position RMSE, vel/acc R²) and
  Step 5 renders to GT RGB (PSNR, SSIM).

Prerequisites:
  - ${OUT}/step4c/trajectory_predicted.csv
  - ${SCENE_DIR}/object_poses.csv
  - ${OUT}/step5/renders/*.png
  - ${SCENE_DIR}/rgb/camXX/frameXXXXX.png

Command:

  python scripts/bounce/step6_eval.py \
    --predicted "${OUT}/step4c/trajectory_predicted.csv" \
    --gt-poses "${SCENE_DIR}/object_poses.csv" \
    --rendered "${OUT}/step5/renders" \
    --gt-rgb-root "${SCENE_DIR}/rgb" \
    --out "${OUT}/step6"

Trajectory-only (skip render PSNR/SSIM if renders missing):

  python scripts/bounce/step6_eval.py \
    --predicted "${OUT}/step4c/trajectory_predicted.csv" \
    --gt-poses "${SCENE_DIR}/object_poses.csv" \
    --rendered "${OUT}/step5/renders" \
    --gt-rgb-root "${SCENE_DIR}/rgb" \
    --out "${OUT}/step6" \
    --trajectory-only

Arguments:
  --predicted   step4c/trajectory_predicted.csv (held-out frames).
  --gt-poses    object_poses.csv from PyBullet.
  --rendered    step5/renders/ directory.
  --gt-rgb-root Scene rgb/ root (cameras as subfolders).
  --out         Output step6/ directory.
  --fps         For velocity/acceleration R² (default 60).
  --trajectory-only  Skip image metrics.

Outputs (${OUT}/step6/):
  metrics.json, metrics_plot.png

Milestone targets (reported in metrics.json → milestone_pass):
  - pos_rmse_m < 0.05
  - vel_r2 > 0.9
  - PSNR > 25 dB, SSIM > 0.85 (needs scikit-image for SSIM)
